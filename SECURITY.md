# Security and privacy reports

This prototype has not received an independent security audit. Accessibility access is powerful, so review the source and grant access only to the app you intend to use.

Do not post credentials, raw conversation content, hook backups or unredacted runtime logs in public issues. For a suspected vulnerability, use GitHub's private vulnerability reporting if available on this repository. If it is unavailable, open a content-free issue asking for a private contact channel, then wait for that channel before disclosing details.

The observer must remain passive: no approval decisions, trust-hash modifications, prompt injection or tool-parameter edits. Missing/incompatible status sources must not be advertised as task completion.
