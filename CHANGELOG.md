# Changelog

## 0.5.1

First public release. Adds optional workspace/app/serial configuration, source-only build isolation, installer-owned uninstall, local-path checks, exact wiring data, MIT licensing, public docs, hardware demo and CI. Keeps the accepted input and LED protocol.

## 0.5.0 prototype

Added passive real-task lifecycle lights, latest-main-task selection, question/permission waiting and metadata-only state handling. The real question-wait/resume/end light sequence received physical acceptance.

## Earlier prototype stages

Built four independent physical inputs, then integrated dictation, project chat creation, cancellation/draft clearing and native live voice. Cancellation changed from an accepted API call to a verified live-control click and observed outcome.
