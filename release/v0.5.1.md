# Arduino Agent Console v0.5.1

First public source release of the four-button, three-light UNO R3 console for desktop agent interaction.

## Included

- UNO firmware with 30 ms debounce and bidirectional 115200-baud protocol.
- Native Swift macOS menu-bar bridge, source build and pure self-test.
- Optional local project/app/serial configuration with validated paths.
- Seven passive Codex task observers, merge/backup installer and targeted uninstall.
- Exact breadboard wiring JSON, editable SVG, PNG overview and BOM.
- English and Chinese README, setup, architecture, privacy, acceptance record and build journal.
- Hardware-only demo with audio removed, separate from desktop acceptance.

## Downloads

- `arduino-agent-console-v0.5.1-source.zip`: source, docs, diagrams and hardware demo, excluding build caches and private configuration.
- `Arduino-Voice-Bridge-v0.5.1-macos-arm64.zip`: Apple Silicon app, locally ad-hoc signed, not notarized. Requires normal Accessibility setup. Build from source for another architecture.
- `SHA256SUMS.txt`: checksums for the attached archives.

GitHub also provides automatic source archives. Platform tools and services are not bundled or re-licensed.

## Validation boundary

The original `0.5.0` physical prototype accepted all four desktop actions and a real yellow/red/yellow/green task sequence. Permission-request waiting was not physically observed. The public `0.5.1` portability changes have automated/build verification and need acceptance on a reader's own installation.

Green means turn ended/idle, not that AI output is correct. Text stays unsent for human review. No productivity improvement is measured. macOS/Codex shortcuts, accessibility labels and the read-only internal SQLite thread filter are version-sensitive.

See the [build guide](https://github.com/maozexi103-rgb/arduino-agent-console/blob/main/docs/getting-started.md) and [test record](https://github.com/maozexi103-rgb/arduino-agent-console/blob/main/docs/testing.md).
